# NGC project website

Public project page for Neighborhood Graph Cost (NGC).

- Website: https://ngc-latent-manifold.github.io/
- Research code: https://github.com/youzunzhi/ngc-latent-manifold

GitHub Pages publishes the repository root from `main`. Edit `index.html`, `styles.css`, `app.js`, or `assets/`, then push to `main`. No build step is required.

To preview locally, run `python3 -m http.server 8000` and open http://localhost:8000/.
